# 电商核心链路接口自动化测试框架

## 项目简介
基于 Pytest + Requests 搭建的电商业务接口自动化框架，包含数据驱动、全局鉴权、日志记录与数据库一致性校验。

## 设计取舍与踩坑记录（这是我自学最大的收获）
- **Fixture 鉴权**：使用了 `scope="session"` 实现全局登录，极大节省了时间。
- **数据提取**：前期用 `[]` 取值，遇到接口少返回字段就报 `KeyError` 崩溃。后来查阅资料，改用字典的 `.get()` 链式取值，实现了防御性编程。

## 待优化方向

- 增加网络抖动时的失败重试机制
